# 微信小程序零基础实操指南

一份面向个人开发者的纯文字入门教程，记录我从零开发并发布小程序「浮光闪藏」时走过的完整流程：账号准备、AppID、认证与备案、AI 辅助开发、调试、真机验证、隐私配置、上传、审核与发布。

这不是一份完整的编程教材，而是一张尽量少走弯路的实操路线图。适合没有系统编程经验、希望借助 Codex 等 AI 编程工具完成第一个小程序的人。

> 本仓库只保留 Markdown 文字，不包含截图、设计素材、项目源码、AppID、AppSecret、访问令牌或其他账号信息。

## 阅读入口

- [查看完整教程](./guide.md)

## 你会走过的流程

明确功能 → 注册账号 → 获取 AppID → 完成认证与备案 → 安装开发者工具 → 创建项目 → AI 辅助开发 → 编译与真机验证 → 配置隐私信息 → 上传 → 审核 → 发布

## 适合谁

- 第一次制作微信小程序的个人开发者
- 不熟悉 WXML、WXSS、JavaScript 和 JSON 的新手
- 希望使用 AI 编程 Agent，但不知道如何验证代码是否真正生效的人
- 已经能生成代码，却容易卡在备案、权限、真机调试或审核环节的人

## 这份指南强调什么

- 第一版先做最小可运行功能，不把需求一次堆满
- AI 生成代码之后，必须经过编译、模拟器与真机验证
- 注册、认证、备案、代码审核和发布是不同环节
- 隐私说明只填写实际使用的权限和数据
- 公开仓库中不保存密钥、令牌、个人资料和敏感日志

## 项目背景

本指南整理自个人小程序「浮光闪藏」的实际开发过程。项目涉及用户选择图片、页面展示与收藏、设备摇动交互等功能，因此在实践中遇到了个人主体能力边界、加速度传感器、照片选择、隐私指引、真机测试和审核发布等问题。

文档将这些具体经验抽象成一套新手也可以复用的操作顺序，但不会公开项目源码与账号信息。

## 使用说明

平台界面、服务类目、资质要求、隐私规则和审核标准可能变化。遇到与本文不同的情况时，请以微信公众平台、微信开放文档和当前后台提示为准。
